# Reader feedback

Each entry comes from a "More like this" or "Less like this" link on the site
(visible after visiting the site once with `?tune=1`), filed as a GitHub issue by
the repo owner and appended here by the feedback workflow. The morning run reads
the newest entries, folds lasting lessons into `taste.md`, and moves handled
entries under "Folded in".
